Playback help

  1. Select a channel card to start loading its stream.
  2. If your browser asks for interaction, select Play.
  3. Choose Auto quality or an available resolution in the player.
  4. Use Retry to reconnect to the current channel.

Access denied: HTTP 401 or 403

The provider rejected the request. The channel requires a working URL with legitimate access. Changing the player or deploying to Vercel cannot guarantee access.

Missing stream: HTTP 404 or 410

The saved stream URL is no longer available. The operator must update it using an authorized source.

Timeout or connection failure

Check your connection and try another channel. Provider outages, regional availability and cross-origin restrictions can prevent playback.
